# 轻量图片预览、导航与主题验收

日期：2026-11-01。本轮仅修改前端，不迁移数据库、不替换用户已有文件和站点标志。

## 实现

- 图片采用 vue-easy-lightbox 1.19.0（MIT），外观参考 Ant Design 截图，自定义工具栏复用已有 Lucide 图标。缩放、旋转、拖动、触屏交互由开源引擎负责，额外提供水平/垂直镜像。全屏遮罩、右上关闭、底部工具栏，支持 Esc 和焦点返回。
- 只有打开图片才加载图片引擎，生产构建独立资源为 26.82 kB，gzip 8.51 kB，不包含在首屏同步加载中。本轮最终仅新增这一项依赖，未保留试装的整套文档阅读器和第二套编辑器。
- 富文本继续使用 Tiptap；PDF、Word、Excel、Markdown 继续复用原有 PDF.js、Mammoth、ExcelJS、Marked。原有文档格式与版式边界不变。
- 文件列表、上传前本地图片、消息附件和正文图片共用预览。文件使用已认证 Blob，消息图片使用任务授权接口；关闭或切换释放对象地址，过期请求不能覆盖新文件。
- 图片加载过程使用同一个浮层，不再短暂闪出文档弹窗。图片预览独立 FocusScope 管理焦点，底层 Dialog 临时解除指针锁并阻止意外关闭。
- 侧栏从 224px 减至 204px，子项缩进并增加细分隔线，主色填充的选中项使用白色文字和图标。展开维持单组手风琴；收起只保留工作台及一级目录图标，悬停弹出真实已授权子项，延迟关闭支持跨间隙移动。点击/键盘打开时保留正常聚焦。
- 主题入口支持浅色、深色、跟随系统、七个预设主色及自定义色值。配套色同步导航、按钮、表单、日期、标签、图表和工作区，当前浏览器持久化；主色仍默认 #00b96b。

## 验证

- `pnpm lint:fix`、`pnpm build` 通过；19 个测试文件、81 项测试通过。
- 新增回归覆盖图片预览实例计数、任务授权路径、过期响应隔离、Blob 释放、正文图片鉴权与键盘打开、主题非法色值及浅深模式配色。
- 真实页面验证图片显示、缩放、旋转、翻转、Esc 关闭和焦点返回；上传前本地图片可预览，关闭后上传表单保留。本轮仅选择本地测试图片，没有执行上传写入。
- 真实页面验证收起仅有五个一级入口、悬停系统管理展开子菜单并跳转部门页；展开侧栏实测 204px，选中项实测背景 rgb(0,185,107)、文字 rgb(255,255,255)。
- 切换蓝色及深色模式后刷新仍保留；验收结束恢复默认绿色与浅色。独立验收浏览器不改变用户原浏览器会话。
- 后端未修改、未重新编译或重启。已有 ExcelJS 按需资源超过 500 kB 的构建提示仍存在，本轮图片库没有引入额外子依赖。
