- 修复消息抽屉的遮罩层覆盖正文：统一 Ant Design Vue 的浮层基础层级，抽屉根节点、遮罩和内容层级一致。文件预览使用独立更高层级，关闭后回到原消息。

- 公告正文挂载后记录 `popup_seen_at`，与 `read_at`、主动点击的 `confirmed_at` 分开保存。已展示公告刷新后不重复弹出；展示回执失败会在当前会话重试，避免不断打断操作。撤回、过期、归档和收件人访问范围仍由服务端判断。

- 文件管理、消息发布附件、消息详情共用预览组件，私有文件通过当前身份读取，消息附件必须命中有效消息授权，不通过公开地址绕过权限。
- 共享 Dialog、滚动 Dialog 和 Sheet 移除关闭按钮的永久打开高亮；初始聚焦跳过隐藏的文件输入，键盘 focus-visible 提示保留。
- 系统配置的站点标志改为图片上传、更换和恢复默认，最大 2 MiB；保存后更新侧栏及浏览器 favicon。使用真实内容检测，仅允许栅格图片。当前生效标志受文件删除保护，其他管理员原样保存不必重新拥有该图片。

## 预览范围

| 格式 | 实际能力与边界 |
| --- | --- |
| PNG/JPEG/GIF/WebP/BMP | 图片查看、缩放、旋转 |
| PDF | PDF.js 分页、缩放、旋转，清理 worker，快速切换取消旧画布任务 |
| DOCX | Mammoth 读取正文、标题、表格和内嵌图片；复杂 Word 版式以原文件为准 |
| XLSX | ExcelJS 读取真实单元格，切换工作表；最多 20 个工作表，每表 1000 行、100 列；不计算公式 |
| Markdown | 标题、列表、表格、代码等内容排版，净化后呈现 |
| TXT/CSV/JSON/LOG | 纯文本阅读，最多 200000 字符 |
| DOC/XLS/PPT/PPTX | 服务端 Apache POI 提取实际文本；不承诺图片、复杂图表和原始版式；需先上传 |
| MP3/WAV/OGG/MP4/WebM | 浏览器原生播放，具体编码是否可播放取决于浏览器 |
| ZIP 等其他格式 | 明确显示下载入口，不伪造在线阅读 |

文档在本系统内解析，不发送到外部 Office 查看服务。HTML 去除脚本、事件、危险链接及外部图片，仅保留允许的文档结构与内嵌栅格图。上传大小仍为每文件 20 MiB。
