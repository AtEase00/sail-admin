# 个人中心与导航体验验证

日期：2026-11-03。

## 已完成

- 右上角“个人菜单”中的“个人中心”入口，沿用 `/account` 路由与工作区标签。
- 个人资料：账号、昵称、部门、有效岗位、角色、加入时间；昵称保存后立即同步顶部菜单。当前模型没有手机、邮箱或头像字段，本次不引入无后端支持的表单或数据库扩展。
- 当前登录用户可维护本人昵称；服务端不接受通过个人入口修改身份、部门、状态或角色。资料请求不要求用户管理权限。
- 密码沿用旧密码校验和全设备会话失效机制；离开缓存页面清空密码输入。表单显示提交中、失败原因及资料加载重试。
- 页面进入 180ms、退出 100ms 的淡入淡出与轻微位移；多根页面统一包装成真实 DOM 根节点，兼容 Transition 和 KeepAlive，刷新时只重建当前标签。
- 遵循 `prefers-reduced-motion`，减少动态效果时停用过渡。
